🎲 Jogo dos Dados do Casal - Guia de Impressão

Role 2 dados padrão (1 a 6) • Some os números • Cumpra o Desafio da Carta!

🎲 Como Jogar com os Dados Físicos:
1. Escolha a Categoria: Selecione qual baralho vocês querem jogar hoje (ex: Date Night, Desejo, Sedução, Confissões).
2. Jogue os 2 Dados: Role os dois dados na mesa e some os valores (Resultado de 2 a 12).
3. Encontre a Carta: Procure na categoria o número da soma sorteada nos dados (🎲 Soma = X).
4. Cumpra a Ação: Leiam o momento e cumpram o desafio juntos com carinho e diversão!
